# numa — Complete Release Catalog & Brand Context

## Brand Overview

**numa** is a minimalist YouTube lofi channel that creates "sound journals" — each release captures a single feeling or theme. The brand emphasizes:
- **Visual identity:** Warm paper-like textures, subtle grain, monospace typography (Geist Mono), small top-right mark `n.`
- **Audio:** Original lofi tracks and continuous mixes (10 tracks per release, crossfaded with 2-second transitions)
- **Aesthetic:** Minimalist, warm, calm, unhurried
- **Format:** Each release is a single continuous mix exported as WAV/MP3, paired with static artwork for YouTube videos

### Artwork Specifications
- **Cover:** 3000×3000 PNG (square)
- **YouTube Background:** 3840×2160 PNG (landscape)
- **Background:** Warm gradient + light paper-like grain

- Each release has a unique color palette that matches its theme
- Gradients typically use 2-3 colors
- Text colors are chosen for contrast and mood (dark for light backgrounds, light for dark backgrounds)
- Colors evoke the emotional tone of the release

## Production Workflow

### Standard Release Structure
Each release follows this structure:
```
NNN_theme/
├─ artwork/
│  ├─ cover.png (3000×3000)
│  └─ yt_background.png (3840×2160)
├─ metadata/
│  ├─ info.json (structured metadata)
│  ├─ description.txt (YouTube description)
│  ├─ tags.txt (SEO tags)
│  ├─ tracklist.txt (simple track list)
│  └─ prompt.txt (Suno AI prompt template)
├─ mix/
│  ├─ <release>_mix.wav
│  └─ <release>_mix.mp3 (320kbps)
├─ tracks/ (10 individual WAV files)
└─ videos/
   └─ <release>.mp4
```

### Audio Production
- **Tracks:** 10 tracks per release, generated with Suno AI Pro
- **Mix:** Continuous mix with 2-second crossfades between tracks
- **Format:** WAV (master) and MP3 (320kbps for distribution)
- **Timestamps:** Calculated with 2-second crossfade + 1.00516 adjustment ratio

### Release Themes & Evolution
- **001-002:** Natural elements (sun, rain) with warm/cool palettes
- **003-004:** Urban nocturne themes (neon, city lights, distance)
- **005-006:** Intimate interior spaces (mornings, quiet rooms)
